**Developed by SPY-E | Powered by 123TOOL**

Framework edukasi untuk manajemen alat keamanan siber di Ubuntu, Kali Linux, dan Termux.

## 🛠️ INSTALLATION GUIDE

## **Xubuntu / Ubuntu / Kali Linux**
Buka terminal dan jalankan
## Update Repo
```
sudo apt update && sudo apt install python3 python3-pip git -y
```
## Clone System
```
git clone https://github.com/123tool/Control-Hacking-Manager.git
cd Control-Hacking-Manager
```
## Install Dependencies
```
pip3 install -r requirements.txt
```
## Run System
```
python3 app.py
```
## Termux (Android)
​Jalankan di aplikasi Termux:
```
pkg update && pkg upgrade -y
pkg install python git -y
git clone https://github.com/123tool/Control-Hacking-Manager.git
cd Control-Hacking-Manager
pip install colorama requests
python app.py
```
